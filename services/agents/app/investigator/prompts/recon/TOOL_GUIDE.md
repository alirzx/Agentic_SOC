Resolve accepts a server-issued seed or candidate handle. Context, Neighbors and Timeline accept established entity UUIDs. Use Context to obtain evidence references, Neighbors to inspect a bounded graph hop, Timeline to answer an ordering question, and Search to locate semantically relevant chunks. Use authorized aliases exactly as supplied when a search needs them. Never guess the original value.

Resolve a candidate only when a current Context result links its exact document and chunk through a fact on an established alert root. Similarity, lexical fallback and an excerpt describe retrieval relevance. They do not verify an entity. A bounded altered predicate, window or entity type can justify a new query. A duplicate is not a new observation.
